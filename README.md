# Mohamed Alaa — Portfolio

Personal portfolio site for Mohamed Alaa-Eldin Mahmoud, Infrastructure Engineer at Huawei Technologies.

**Live site:** https://mohamed-alaa-portfolio.malaa20499.workers.dev/

## About

A single-page, animated portfolio built to showcase experience in cloud infrastructure, virtualization, and Huawei Cloud Stack operations — along with certifications, projects, and contact details.

## Tech stack

- Pure HTML, CSS, and vanilla JavaScript — no frameworks or external JS libraries
- Custom particle-network canvas background
- Scroll-triggered animations via `IntersectionObserver`
- Fonts: [Syne](https://fonts.google.com/specimen/Syne) (headings) and [DM Sans](https://fonts.google.com/specimen/DM+Sans) (body), loaded from Google Fonts
- Fully self-contained in one `index.html` file — no build step required

## Sections

- **Hero** — intro, availability status, key stats
- **Skills** — animated skill bars and a technology chip cloud
- **Experience** — career timeline (Huawei Technologies, Telecom Egypt)
- **Projects** — Azure, AWS, and Kubernetes/Docker projects
- **Education & Certifications** — degree, certifications, languages
- **Contact** — email, phone, location, LinkedIn, GitHub

## Running locally

No build tools needed. Just open the file in a browser:

```bash
open index.html
```

Or serve it locally:

```bash
python3 -m http.server
```

## Deployment

Deployed as a static site on **Cloudflare Pages**. Any push to the `main` branch on this repo triggers an automatic redeploy.

- Framework preset: `None`
